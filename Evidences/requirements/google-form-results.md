# Google Forms Results

### Survey Information

| Item                | Details                                                     |
| ------------------- | ----------------------------------------------------------- |
Name of the Questionnaire | Hospital Appointment Booking System User Requirement Survey |
| Platform            | Google Forms                                                |
| Number of Responses | 25                                                          |
| Target Participants | Potential hospital/clinic patients                          |
|Purpose|To determine user expectations and system needs.
| Data Type           | Simulated academic data                                     |

> Note: The below results are simulated for the Academic Hospital Appointment Booking System project and not collected from real users.

## Overall Result

The simulation survey shows that an online Hospital Appointment Booking System is well supported. The most consensus based requirements are: Doctor availability, Online booking, Doctor's booking confirmation, Doctor's cancellation, Doctor's rescheduling, Usability, and Protection of patient information.
