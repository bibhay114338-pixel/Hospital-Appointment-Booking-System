# Hospital Appointment Booking System
## Project Overview
Hospital Appointment Booking System is an academic software development project which is used to simulate real world software project management practices. The project is an example of how a software project can be planned, documented, designed, tested and managed as an agile project.
The project is planned, planned its tasks, managed its Sprint and tracked the progress in **Trello**. Documentation, collaboration, version control, branching, pull requests and maintenance of project files are uses of Github.
This is a NON-CODING PROJECT. This course emphasizes the aspects of project planning, requirement analysis, UML system design, software testing and the application of Agile and version-control tools.
## Project Goal
The main goal of the Hospital Appointment Booking System is to provide an organized and efficient approach for managing appointments between patients and healthcare providers.
The system that is proposed here gives user the facility to search doctors, view available appointment time, book appointments, cancel and reschedule appointments, view appointment information etc. Doctors can see appointment schedules and administrators can manage doctors, doctor availability and appointment records.

## Branching and Pull Request
At least one feature branch is used in the project that is a GitHub feature, to illustrate collaborative version-control techniques.
For example, UML design tasks can be finished on:
`feature/uml-diagrams`
Once the UML work is done, a pull request will be created and merged into the `main` branch. Before the pull request is accepted and merged, another team member checks over the changes.
This is an example of the branching, peer review, pull request and version control that the team has as it works together.
